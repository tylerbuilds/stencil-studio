# Contributing

Use Node.js 22.19+ or 24.11+ on Linux or macOS. Run `npm ci`, `npm test` and `npm run build`, then try your change in the browser with `npm run dev`. In your pull request, explain what changed and how you checked it.

Keep this project local first: no tracking, secrets, paid service requirements or private account captures. Implement features with original code, copy and assets. Put public research sources and clear limits in `docs/research/`. Follow the existing code style. Keep old save files working, or test how they are updated.
