# Contributing

Use Node.js 22.19+ or 24.11+ on Linux or macOS. Run `npm ci`, `npm test` and `npm run build`, then exercise the changed flow in the browser with `npm run dev`. Include observable behaviour and verification in pull requests.

Keep this project local first: no tracking, secrets, paid service requirements or private account captures. Implement features with original code, copy and assets. Put public research sources and clear limits in `docs/research/`. Match the existing code style and preserve save-file compatibility or provide a tested migration.
