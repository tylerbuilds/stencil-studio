# Stencil Studio: all-tier feature comparison

This comparison maps 88 documented Canva workflows across free and premium tiers to an independent implementation. It records delivered behaviour and specific gaps; it does not claim full parity, original algorithms or a complete content catalogue.

| Classification | Rows |
|---|---:|
| implemented-local-equivalent | 15 |
| missing | 41 |
| partial | 32 |

The frozen source snapshot is identified by file hashes in [the comparison JSON](feature-comparison.json). Current Linux Chrome verification passed 20 checks and matches the recorded source. Optional provider/backend and native rendering proofs retain their own component qualifications in [proof metadata](proof-metadata.json). Platform CI, macOS browser behaviour and deployment are separate evidence.

All original authenticated workflows remain unexercised. Public documentation is the source for the workflow inventory, while REA observations cover only anonymous public pages and metadata.
